# ClarityDocs - Supported Languages Quick Reference

## 🌐 Current Language Support (6 Languages)

ClarityDocs now supports document processing in **6 major Indian languages** plus English, covering the majority of the Indian population.

---

## Supported Languages

### 1. **English** (en)
- **Native Script**: Latin alphabet
- **Unicode Range**: U+0020 to U+007E (Basic Latin)
- **Usage**: Global language, default
- **Coverage**: Official language in many countries
- **Sample Text**: "This is a rental agreement between the landlord and tenant."

---

### 2. **Hindi** (हिन्दी) - hi
- **Native Script**: Devanagari
- **Unicode Range**: U+0900 to U+097F
- **Speakers**: ~600 million (native + second language)
- **Official Status**: Official language of India
- **Common Use Cases**: 
  - Rental agreements (किराया अनुबंध)
  - Loan agreements (ऋण समझौता)
  - Employment contracts (रोजगार अनुबंध)
- **Sample Text**: "यह समझौता आज दिनांक को किया गया है। मासिक किराया रु. 15,000 होगा।"

---

### 3. **Tamil** (தமிழ்) - ta
- **Native Script**: Tamil script
- **Unicode Range**: U+0B80 to U+0BFF
- **Speakers**: ~80 million
- **Official Status**: Official language of Tamil Nadu, Sri Lanka, Singapore
- **Common Use Cases**:
  - வாடகை ஒப்பந்தம் (Rental agreements)
  - கடன் ஒப்பந்தம் (Loan agreements)
  - வேலை ஒப்பந்தம் (Employment contracts)
- **Sample Text**: "இந்த ஒப்பந்தம் இன்று தேதியிட்டது. மாதாந்திர வாடகை ரூ. 15,000."

---

### 4. **Telugu** (తెలుగు) - te
- **Native Script**: Telugu script
- **Unicode Range**: U+0C00 to U+0C7F
- **Speakers**: ~95 million
- **Official Status**: Official language of Andhra Pradesh and Telangana
- **Common Use Cases**:
  - అద్దె ఒప్పందం (Rental agreements)
  - రుణ ఒప్పందం (Loan agreements)
  - ఉద్యోగ ఒప్పందం (Employment contracts)
- **Sample Text**: "ఈ ఒప్పందం ఈ రోజు తేదీతో చేయబడింది. నెలవారీ అద్దె రూ. 15,000."

---

### 5. **Kannada** (ಕನ್ನಡ) - kn
- **Native Script**: Kannada script
- **Unicode Range**: U+0C80 to U+0CFF
- **Speakers**: ~65 million
- **Official Status**: Official language of Karnataka
- **Common Use Cases**:
  - ಬಾಡಿಗೆ ಒಪ್ಪಂದ (Rental agreements)
  - ಸಾಲ ಒಪ್ಪಂದ (Loan agreements)
  - ಉದ್ಯೋಗ ಒಪ್ಪಂದ (Employment contracts)
- **Sample Text**: "ಈ ಒಪ್ಪಂದವನ್ನು ಇಂದು ದಿನಾಂಕದಂದು ಮಾಡಲಾಗಿದೆ. ಮಾಸಿಕ ಬಾಡಿಗೆ ರೂ. 15,000."

---

### 6. **Malayalam** (മലയാളം) - ml
- **Native Script**: Malayalam script
- **Unicode Range**: U+0D00 to U+0D7F
- **Speakers**: ~38 million
- **Official Status**: Official language of Kerala and Lakshadweep
- **Common Use Cases**:
  - വാടക കരാർ (Rental agreements)
  - വായ്പാ കരാർ (Loan agreements)
  - തൊഴിൽ കരാർ (Employment contracts)
- **Sample Text**: "ഈ കരാർ ഇന്ന് തീയതിയിട്ടത്. പ്രതിമാസ വാടക രൂപ 15,000."

## Font Rendering Support

All supported scripts render correctly in modern browsers using:

| Script | Unicode Block | Web Safe | Font Fallback |
|--------|---------------|----------|---------------|
| Latin (English) | U+0020-007F | ✅ Yes | Arial, Helvetica |
| Devanagari (Hindi) | U+0900-097F | ✅ Yes | Noto Sans Devanagari |
| Tamil | U+0B80-0BFF | ✅ Yes | Noto Sans Tamil |
| Telugu | U+0C00-0C7F | ✅ Yes | Noto Sans Telugu |
| Kannada | U+0C80-0CFF | ✅ Yes | Noto Sans Kannada |
| Malayalam | U+0D00-0D7F | ✅ Yes | Noto Sans Malayalam |

**Note**: Google Fonts Noto Sans family provides excellent rendering for all Indian scripts.

## Adding More Languages

Want to add more? It's easy! Just update the language hints array:

```typescript
languageHints: [
  'en',  // English
  'hi',  // Hindi
  'ta',  // Tamil
  'te',  // Telugu
  'kn',  // Kannada
  'ml',  // Malayalam
  'bn',  // Bengali (বাংলা) ← ADD THIS
  'mr',  // Marathi (मराठी) ← ADD THIS
  'gu',  // Gujarati (ગુજરાતી) ← ADD THIS
  'pa',  // Punjabi (ਪੰਜਾਬੀ) ← ADD THIS
]
```

All are supported by Google Document AI!
